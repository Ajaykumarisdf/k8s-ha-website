🏗️ Why AWS S3 + EFS Enables True High Availability

A comprehensive look at how multi-tier storage protects against pod evictions, node crashes, and storage bottlenecks:

⚡
Zero Node Disk Exhaustion
Streaming heavy video files directly from pods or local disk causes node storage pressure (as seen with disk evictions). S3 completely offloads media data from EC2 worker nodes.
🔄
HTTP Range Requests
The backend API forwards HTTP 206 Partial Content range headers directly to S3. Clients only buffer the exact seconds of video they are watching, keeping pod memory below 64 MB.
🛡️
Multi-AZ Persistence
If all 3 Kubernetes nodes are rebooted or redeployed during rolling updates, zero videos are lost. S3 stores objects across at least three physical Availability Zones in AWS us-east-1.
