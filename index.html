💡 How AWS EFS provides High Availability: When you upload an image below, it is written to the shared file system volume (efs-website-pvc). Because EFS supports ReadWriteMany (RWX), all 3 frontend pods and 2 backend pods running across different EC2 worker nodes immediately have shared access to this file. Pod restarts or node failures do not cause data loss.
